사용자가 요청한 기능에 대한 구현 계획을 수립합니다.

## 입력

$ARGUMENTS — 구현하려는 기능 설명 (예: "실험실 목록 페이지에 검색 필터 추가")

## 절차

1. `feature-planner` 서브에이전트(Opus 모델)를 호출하여 상세 계획 수립
2. 다음 정보를 포함한 계획을 받아 사용자에게 제시:
   - 요구사항 정리
   - 영향 받는 파일 목록
   - 재사용할 기존 코드
   - 데이터 흐름
   - 구현 단계 (순서)
   - 테스트 전략
   - 위험 요소

3. 계획 출력 후 사용자에게 다음 단계 안내:
   > 다음 단계: `/verify-plan` 으로 계획을 재검증한 후 `/implement` 로 구현을 시작하세요.

## 주의

- 이 단계에서는 **코드를 작성하지 않습니다**
- `feature-planner`는 읽기 전용 도구만 사용 (Read, Grep, Glob, WebFetch)
- Opus 모델로 비용은 들지만 환각·설계 결함 최소화가 목적

## Agent 호출 예시

서브에이전트 호출 시 다음 정보를 명확히 전달:

- 기능 설명 (사용자 입력 그대로)
- 프로젝트 컨텍스트는 CLAUDE.md를 통해 자동 로드됨
- 출력 형식은 `feature-planner` 에이전트 정의에 명시됨
